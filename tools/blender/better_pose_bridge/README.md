# BetterPose Blender Bridge

这个插件使用 BetterPose 的 `.bpmotion` 文件在 Blender 和游戏之间交换已经适配好的动作。
文件包含游戏骨骼名称和父级、姿态关键帧、根位移、表情以及可选的姿势镜头；不包含角色模型。

已实际验证 Blender **3.5.1** 和 **4.2.14 LTS**。4.2 测试覆盖插件注册、骨架与动作导入、
F-Curve 生成、修正层、镜头轨道和 `.bpmotion` 重新导出。

## 使用

1. 在 Blender 的插件管理器中选择本目录安装并启用 **BetterPose Blender Bridge**。
2. 在 3D 视图按 `N`，打开 **BetterPose** 面板。
3. 用 **导入 .bpmotion** 打开游戏导出的动作，在 Blender 中编辑骨骼或镜头。
4. 用 **导出 .bpmotion** 保存，回到 BetterPose 的 **MMD** 页点击
   **导入 Blender 为 MMD**，或在关键帧页点击 **导入 Blender 动作为 MMD**。

导出的 `.bpmotion` 是完整的离线动作文件，不需要保持 Blender 连接。游戏导入后会依据当前
角色的参考姿态生成原生 MMD 动作，可正常暂停、拖动、循环、物理和卸载，也会出现在 MMD
页的动作时间轴中。离线导入会烘焙骨架、根位移和表情，并把 Blender 镜头载入独立的
CameraTrack；是否接管游戏镜头仍由 **驱动镜头** 开关决定。

导入动作会创建一个只包含游戏骨架的 Armature，默认使用 30 FPS。导出的帧范围取 Blender
场景的起止帧，动作第一个文件帧对应 Blender 的场景起始帧。表情以骨骼之外的轨道保存，
回到游戏后仍由 BetterPose 的表情映射处理。

## 修正层

在 Pose 模式选中躯干、四肢或手指关节，使用 Blender 原生的 `G`、`R`、`S` 调整姿态，
然后点击 **给选中关节打关键帧**。首次打帧会自动把已导入动作保留为下层 NLA 轨道，并建立
独立的 **BetterPose Correction** Action；只有选中关节会写入修正层。

面板可在 **编辑原动作** 和 **编辑修正动作** 之间切换。编辑原动作会进入原 Action 的 NLA
Tweak 模式；两种模式打出的关键帧分别写入原 Action 或修正 Action。

让修正只持续一段并在后面回到原动作时，在目标帧选中相关关节，点击 **恢复选中关节状态**，
再点击 **给选中关节打关键帧**。这会写入一个零修正关键帧；从上一修正帧到该帧平滑回退，
之后继续跟随原动作。镜头使用相同流程： **恢复下层镜头** 后点 **镜头打关键帧**。

到另一帧点击 **恢复选中关节状态**，再点 **给选中关节打关键帧**，即可把修正平滑地返回
到底层动作。修正层保存在 `.blend` 工程中，导出 `.bpmotion` 时会烘焙最终叠加结果。

## MMD 表情

连接游戏后会读取当前角色的 morph 列表，并在骨架对象上建立
`betterpose.face.<名称>` 属性。BetterPose 面板可搜索并调整这些属性；点击
**表情打关键帧** 会把全部表情权重写入原动作层，**表情归零** 可恢复中性表情。
实时预览和 `.bpmotion` 导出都会携带表情值，断开会自动把 Blender 接管的 morph 还给游戏。
表情关键帧固定写入原动作层；即使当前正在编辑动作修正层，也不会把表情写入修正 Action。
**查看表情关键帧** 会把窗口底部的 Timeline 或已有 Dope Sheet 切到 Action Editor，不会改动
当前 3D 视图布局。

## 镜头修正层

使用 **编辑镜头** 选中当前 Camera 对象，在 Blender 中用 `G`、`R` 调整位置和朝向，也可修改
焦距与对焦距离。点击 **镜头打关键帧** 时，首次使用会自动把原镜头放入下层 NLA，并建立
**BetterPose Camera Correction**。到另一帧点击 **恢复下层镜头**，再打关键帧即可平滑返回
原构图。连接时会记录整段 Blender 镜头作为基准，并自动勾选
**将 Blender 最终镜头同步到游戏**；未编辑时每帧增量都是零，因此原 CameraTrack 保持不动。
只有实际修改镜头后才叠加差异。取消勾选可立即恢复原始 CameraTrack。

镜头修正使用独立的叠加层：原镜头关键帧保留在 NLA 底层，未添加修正的区间继续播放原镜头，
不会因为新增一个修正关键帧而被单帧姿态覆盖。面板中的 **编辑原镜头** 和 **编辑修正**
可分别进入原镜头 NLA Tweak 模式或镜头修正 Action，两层都可以直接打关键帧。

连接游戏后，Blender 时间轴会实时同步到游戏；如果游戏中已有 MMD 动作，BetterPose 会先
暂停它，断开 Blender 后恢复原来的播放状态。原始 VMD 不会被覆盖。也可以先用离线文件交换
确认 Blender 的修正结果，再连接同一角色预览。

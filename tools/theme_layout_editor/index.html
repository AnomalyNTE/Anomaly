运行时约束

导入校验、属性面板输入、画布拖拽缩放都按运行时（src/ui/platform_ui_layout.cpp）的 同一套范围收敛，保证「编辑器里看到的 = 运行时画出来的」：

  • 贴纸 x/y：-4 ~ 5（非法回退 0.5）
  • 贴纸 width/height：0 ~ 8（非法回退 0）
  • 贴纸 rotation：-3600 ~ 3600 度（非法回退 0）
  • opacity / 背景 opacity：0 ~ 1（非法回退 1）
  • surfaceOpacity：0.15 ~ 1（非法回退 1）
  • canvas.width/height：1 ~ 32768（非法回退 1180 / 700）
  • 贴纸数量 ≤ 64、path ≤ 512 字符、文件 ≤ 256 KB，超出则整个文件被运行时拒绝
  • schemaVersion 为整数且 ≠ 1 时整个文件被拒绝；没有 path 的贴纸会被丢弃

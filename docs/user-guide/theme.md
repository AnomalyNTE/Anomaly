# 主题与背景

Anomaly 的界面外观由两部分组成，两者都同时作用于**游戏内主界面**（`Anomaly.Core.dll`）和 **Anomaly Launcher**：

| 部分 | 决定什么 | 存放位置 |
| --- | --- | --- |
| **配色（palette）** | 窗口底色、按钮重点色、文字与边框颜色 | `Anomaly\config\platform-settings.json` |
| **布局（layout）** | 背景图片、贴纸、面板不透明度 | `Anomaly\config\themes\` |

配色在界面里选，布局在网页编辑器里做。

**布局文件名决定作用范围**：`config/themes/` 下有两个层级——`<配色名>.json`（例如 `naiwa.json`）是**主题专属布局**，只在该配色下生效，装的是这个主题的贴纸和它自带的壁纸；`layout.json` 是**通用布局**，对所有配色生效。

**背景图是全局的**：你在设置里启用并选了一张图，它写进通用布局并作用于所有配色——**包括自带壁纸的主题**（选图会盖掉主题自带的那张）；取消勾选后通用布局里就不再留背景，各主题自带的壁纸自动回来。**背景透明度（面纱 `surfaceOpacity`）同样是全局的**：设置界面里的滑块写进通用布局，所以它对所有配色生效，也会盖掉主题文件里自带的值。

**出厂只带 Naiwa 预设**：`config/themes/naiwa.json` 和它的三张贴纸随包附带，因为奶蛙是默认配色，主界面开箱就是这个样子。其余文件都不预置，布局在你**第一次修改背景或贴纸时**才生成，所以重新编译、重新部署都不会覆盖你自己选的东西。

## 内置配色

**设置 > 界面 > 配色** 中可选：

| 配色 | 底色 | 重点色 | 说明 |
| --- | --- | --- | --- |
| Anomaly Hub | 深色 | 青色 | 默认 |
| Naiwa / 奶蛙 | `#ffeeba` | `#fcce44` | 奶黄底色 + 暖黄重点色，适合配浅色背景图 |
| 其余内置配色 | — | — | 见界面内的即时预览 |
| 自定义 | 任选 | 任选 | 逐项取色 |

选择后立即生效并写入 `platform-settings.json`，启动器下次启动时读取同一份设置，因此两个界面永远一致。

## 背景图片的三种填充方式

布局文件的 `background.mode` 决定图片如何铺满界面：

| 模式 | 行为 | 适用 |
| --- | --- | --- |
| `center` | **居中**：等比缩放到完整可见，四周留白，不裁剪 | 想让整张图都看得见 |
| `crop` | **裁剪**：等比缩放到铺满，超出部分按中心裁剪 | 最常见的“壁纸”效果 |
| `stretch` | **拉伸**：直接拉伸到界面尺寸，不保持比例 | 纯色/渐变或可接受形变的图 |
| `disabled` | 不画背景 | 关闭 |

图片支持 PNG / JPEG / BMP / GIF 首帧。**PNG 的 alpha 通道会被完整保留**，因此可以用带透明区域的背景图；没有 alpha 通道的图片会按不透明处理。

### 面板不透明度

`surfaceOpacity` 控制盖在背景图上的那层界面底色的不透明度（`0`–`1.0`，设置界面的「背景透明度」滑块对应 `0%`–`100%`）。`1.0` 表示底色完全不透明、背景图被遮住；`0` 表示完全不压暗、图片满强度显示；调到 `0.6` 左右背景图明显透出来，文字、边框和重点色始终保持不透明，不影响可读性。贴纸画在这层底色**之上**，所以调低它不会让贴纸褪色。

界面从下往上的叠放顺序是固定的：

```
窗口底色  →  背景图  →  面纱(surfaceOpacity)  →  贴纸  →  面板 / 按钮 / 文字
```

所以纯色面板**不会**盖住贴纸（面板底色的不透明度由 `surfaceOpacity` 统一控制），贴纸也**不会**盖住任何文字和按钮——它们永远画在贴纸之上。

### 超出窗口

贴纸不受主界面窗口的裁剪限制：把 `x`/`y` 放到 `0` 或 `1` 之外，贴纸就会**溢出到窗口外面**，做出"裸眼 3D"的贴出效果。`x`/`y` 允许 `-4`–`5`，也就是最多可以推到离屏 4 个界面的距离。

游戏内嵌模式下覆盖层铺满整个游戏窗口，溢出部分能完整显示；独立窗口模式下窗口紧贴主界面，溢出的可见范围取决于窗口四周的余量。

## 贴纸

`stickers` 是一个数组，每项描述一张贴在界面上的图片：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `path` | 字符串 | 图片路径，相对 `Anomaly\`，不能写出根目录之外 |
| `x` / `y` | 0–1 | 锚点在界面中的归一化位置（`0.5` 是正中） |
| `width` / `height` | 0–1 | 归一化尺寸；只填一个时按图片比例自动算另一个，都填 `0` 表示用图片原始像素 |
| `anchor` | 枚举 | `center` / `top_left` / `top_right` / `bottom_left` / `bottom_right`，决定 `x`/`y` 对齐到贴纸的哪个角 |
| `rotation` | 角度 | 顺时针为正，绕贴纸中心旋转 |
| `opacity` | 0–1 | 整张贴纸的透明度 |
| `tint` | `#RRGGBB` | 颜色调制，`#ffffff` 表示原色 |
| `layer` | 枚举 | `behind`（默认，推荐）画在面纱之上、文字按钮之下，既不透明也不遮挡控件；`front` 画在**所有内容之上**，贴纸会压住它下面的文字和按钮 |
| `flipX` / `flipY` | 布尔 | 水平 / 垂直镜像 |

最多 64 张贴纸，整个文件不超过 256 KB。相同路径的图片只读取一次。

## 用网页编辑器制作布局

`tools/theme_layout_editor/index.html` 是一个**完全离线**的单文件编辑器，双击用浏览器打开即可，不需要装任何东西，也不联网。

1. 打开编辑器，把 PNG 素材拖进画布。**背景图不是必须的**：不导入也能编辑，画布上默认画着按真实比例排布的「标题栏 / 侧边导航 / 内容区 / 状态栏」参考骨架，方便判断贴纸会不会压到控件。
2. 拖动摆放、拉角缩放、用旋转手柄转向；右侧属性面板可以精确填 `x`/`y`/尺寸/旋转/透明度/tint，并切换 `anchor`、`layer`、镜像。画布四周留有一圈「窗口外」区域，把贴纸拖出去就能直接看到溢出效果，不会被截断。
3. 顶部切换背景填充方式（居中 / 裁剪 / 拉伸）并调 `surfaceOpacity`，所见即所得。
4. 点 **导出 JSON** 得到布局文件（放进 `Anomaly\config\themes\`，文件名用配色名就是专属布局，用 `layout.json` 就是通用布局），点 **导出 ImGui** 得到等价的 ImGui 绘制代码（`AddImage` / `AddImageQuad`），便于直接嵌进自己的界面代码。

画布尺寸建议与 `canvas` 一致（默认 `1180×700`，即游戏内主界面的默认大小）；贴纸用归一化坐标，所以界面被拖动缩放后位置依然正确。

把导出的文件放进 `Anomaly\config\themes\`，存盘后游戏内界面会自动重新加载，不需要重启。设置页同时显示当前布局的状态：背景模式、贴纸数量和面板不透明度；文件有问题时会直接显示被拒绝的原因。

启动器会在下次启动时读取同一份布局。

## 排错

| 现象 | 原因 |
| --- | --- |
| 贴纸或背景没出现 | 先看文件是不是放在 `Anomaly\config\themes\` 下，再确认文件名（`layout.json` 或 `<配色名>.json`）和 `assets/images/` 里的图片路径都对得上 |
| 设置页显示“布局被拒绝：…” | JSON 语法错误、`schemaVersion` 不是 `1`、贴纸超过 64 个或路径越出根目录 |
| 背景图不显示 | `background.mode` 是 `disabled`，或 `path` 指向的文件不存在 |
| 贴纸不显示 | `path` 错误；`width`/`height` 同时为 `0` 且图片读取失败；或贴纸被更高层级的贴纸盖住 |
| 贴纸溢出部分看不到 | 独立窗口模式下窗口紧贴主界面，四周余量不足；游戏内嵌模式不受此限制 |
| 背景图变形 | `mode` 用了 `stretch`，改成 `crop` |
| 界面文字看不清 | `surfaceOpacity` 太低或背景图太花，调高它，或给文字换成对比更强的配色 |
| 贴纸看不见 | 用 `layer: "front"` 时贴纸会连同它的透明区域一起画在最上层；检查 `path` 与 `width`/`height`，并确认它没有被另一张 `front` 贴纸完全盖住 |

# Better Pose Blender 联动

Better Pose 提供一个可选的 Blender 骨架编辑桥。它只交换骨骼、根位移、表情和关键帧数据，
不导入角色模型，也不会修改原始 VMD。

已在 Blender **3.5.1** 和 **4.2.14 LTS** 上验证。4.2 的测试覆盖插件注册、动作与修正层
创建、镜头轨道和 `.bpmotion` 导出。

## 安装

1. 在游戏中启用 Better Pose 并进入角色场景。
2. 在 Blender 的插件管理器中从磁盘安装 `tools/blender/better_pose_bridge`，启用
   **BetterPose Blender Bridge**。
3. 在 3D 视图按 `N`，打开 **BetterPose** 面板并点击 **连接游戏**。

连接后，勾选 **实时同步到游戏**，Blender 当前帧的骨骼旋转和根位移会发送到游戏。停止同步
或点击 **断开并恢复游戏** 后，Better Pose 会释放对姿态的接管。

连接时会先记录整段 Blender 镜头作为基准，并自动启用
**将 Blender 最终镜头同步到游戏**。未编辑时逐帧增量为零，因此游戏原 CameraTrack 不变；
实际修改后才叠加差异。取消勾选会立即恢复原始 CameraTrack。

镜头编辑会单独建立叠加修正层。原镜头关键帧保留在 NLA 底层，只有实际打过修正关键帧的
区间才会叠加调整，其余时间继续使用原镜头的运动。使用 **查看原镜头** 和 **查看修正**
可以在 Action Editor 中分别显示两层关键帧。

## 离线动作交换

在 Better Pose 关键帧页点击 **Export Blender .bpmotion**，再在 Blender 面板点击
**导入 .bpmotion**。编辑骨架后点击 **导出 .bpmotion**，回到游戏点击
**导入 Blender 动作为 MMD**。文件中保存游戏骨骼名称和父级关系，因此不需要 PMX 模型。
导入后会生成完整的 Better Pose MMD 动作并显示在 **MMD** 页，不需要保持 Blender 连接，
可直接使用普通的播放、暂停、拖动、循环、物理和卸载功能。MMD 页的 **载入动作** 选择器
也接受 `.bpmotion`。

`.bpmotion` 使用 30 FPS 的时间轴，动作、表情和镜头轨道可以随关键帧一起保存；转换器产生的
每帧局部位移（例如脚部/脊柱的 `boneOffsets`）以及根位移缩放也会随动作传给 Blender，避免
Blender 预览和游戏播放出现脚底悬空的差异。回载时，Blender 的局部旋转增量会按当前角色的
参考姿态还原成 MMD 绝对局部旋转，根位移、骨骼局部位移、已编辑表情和镜头会一起载入；
镜头写入独立的 CameraTrack，仍由 **驱动镜头** 开关决定是否接管游戏相机。角色校准和表情
映射继续由 Better Pose 在回载时处理。

`.bpmotion` 中的镜头 FOV 使用 MMD 的垂直视场角。Blender 面板会在编辑和导出时自动换算，
避免把水平视场角误当成垂直视场角，造成镜头拉近或只拍到角色下半身。

已载入 MMD 动作时，姿态库的 **保存当前姿态** 会记录播放头当前帧的完整局部骨骼变换和
表情，包括脚、脊柱等局部位移。应用该姿态库条目时会卸载正在播放的 MMD 并切换到保存的
静态姿态。
拉取按连续时间块批量取样，并按动作 FPS 写入 Blender 时间轴；长动作不会再按单帧往返请求。

动作面板可在 **编辑原动作** 和 **编辑修正动作** 间切换；镜头面板同样提供 **编辑原镜头**
和 **编辑修正**。原层通过 NLA Tweak 模式编辑，修正层使用独立 Action 叠加。表情关键帧固定
写入原动作层，不会写入动作修正层。

若修正只应持续几帧，在需要恢复的帧先点击 **恢复选中关节状态**，再点击
**给选中关节打关键帧**，即可写入零修正并让后续重新跟随原动作。镜头则先点
**恢复下层镜头**，再点 **镜头打关键帧**。

实时桥只监听本机 `127.0.0.1:18923`，Better Pose 停止或热重载时会关闭服务并恢复角色姿态。

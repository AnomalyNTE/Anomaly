# AutoTaxi（自动出租车）0.1.4

独立的 Anomaly 出租车插件，插件 ID：`b1ank.autotaxi`。

## 新增与调整

- 自动请求接客、送达，并在结算后继续下一单。
- 显示游戏确认的新增订单数。
- 文件夹统一为 `Autotaxi`，英文名为 AutoTaxi，中文名为“自动出租车”。
- 兼容配置接入框架 Profile 和签名更新服务。

## 修复

- 修复首次读取字段失败后一直等待的问题。
- 完善接口和对象校验；操作未获确认时停止本单重试。

## 使用

1. 将完整 `Autotaxi` 文件夹放入 `Anomaly/plugins/`，在插件管理器中启用“自动出租车”。
2. 驾驶出租车，在游戏内点击“开始接单”。
3. 打开插件窗口，勾选“启用出租车自动完成”。

启动或重载后，自动完成开关默认关闭。特殊乘客事件和对话按游戏流程处理，可能需要手动完成。车费按游戏规则结算。

从旧版升级时移除原 `Taxi` 文件夹，再启用 ID 为 `b1ank.autotaxi` 的新版。

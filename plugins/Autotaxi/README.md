# AutoTaxi（自动出租车）0.1.11

独立的 Anomaly 出租车插件，插件 ID：`b1ank.autotaxi`。

## 新增

- 自动请求接客、送达，并在结算后继续下一单。
- 显示游戏确认的新增订单数。
- 预选下一次偶遇角色，可与自动接送一起使用；列表按当天可偶遇名单、已持有角色及乘客配置筛选。
- 角色名单显示游戏当前语言的名称，支持搜索、翻页及三列开关选择，每页 12 名角色。
- 对话和特殊事件期间等待，结束后继续自动接送。

## 调整

- 每次预选只使用一次，可以手动取消；玩家、场景或出租车变化后需重新选择。
- 移除偶遇功能的“测试”标记。
- 兼容数据使用框架公开的 Profile 快照、签名解析及入口校验接口。

## 修复

- 修复自动接送一直处理普通订单、不使用预选角色的问题。
- 修复重登后刷新名单仍使用旧会话接口，以及角色名显示为数字 ID 的问题。
- 修复角色对话或特殊事件结束后无法继续送达的问题。

## 使用

1. 将完整 `Autotaxi` 文件夹放入 `Anomaly/plugins/`，在插件管理器中启用“自动出租车”。
2. 在主场景驾驶出租车。需要角色偶遇时，先点击“刷新”，搜索或翻页找到角色，打开对应开关。
3. 勾选“启用出租车自动完成”，在游戏内点击“开始接单”。不预选角色时按普通订单运行。
4. 遇到角色对话或特殊事件，按游戏流程完成；插件随后继续接送。关闭角色开关或点击“取消预选角色”可取消待使用的预选。

启动或重载后，自动完成默认关闭，角色预选清空。车费和偶遇收益按游戏规则结算，每日偶遇记录保持不变。重登或换车后，重新驾驶出租车并刷新名单。

## 构建

需要 Windows x64、Visual Studio 2022 C++ 工具、Windows SDK、CMake 3.22+ 和 PowerShell 7+。在 Anomaly 仓库根目录执行：

```powershell
cmake --preset windows-vs2022
cmake --build --preset windows-relwithdebinfo --target anomaly_builtin_autotaxi --parallel
```

成品目录：`.build/windows-vs2022/bin/RelWithDebInfo/builtin-plugins/Autotaxi/`。将整个目录复制到运行时的 `Anomaly/plugins/Autotaxi/`。

# 载具飞行

载具飞行随 Anomaly 游戏运行包提供。在「平台设置 → 高级」开启「开发者模式」后，插件才会显示。启用插件后，在驾驶位打开「载具飞行」窗口，再勾选「启用载具飞行」。关闭开发者模式会停止飞行。

WASD 按视角的水平方向移动，空格上升，Ctrl 下降。Shift 三倍加速，最高 1000 米/秒。按下立即移动，松开立即悬停。飞行时隔离本地驾驶输入，并清除驾驶组件里已有的油门和转向指令。

车身在飞行时保持水平，并清除车身线速度和角速度。按下水平移动键时车身立即对齐镜头方向，不做转向插值，单独升降不改变车头朝向；按键位移和松手悬停仍立即响应。无碰撞模式省去同一帧的重复位置回读，下帧继续检查游戏修正；有碰撞模式仍立即回读检测阻挡。连续位移从上一次飞行目标累加，不逐帧遍历附属组件。下车后暂停飞行，在同一场景重新坐进驾驶位时自动恢复。关闭飞行时先清除残余线速度和角速度、恢复阻尼与重力，最后恢复整车碰撞并交还驾驶输入，切换场景会自动停用飞行。

点「飞行快捷键」后按键即可绑定。支持 Ctrl、Shift、Alt 组合键，再按同一快捷键可关闭飞行。「飞行速度」可在 3–1000 米/秒之间调整。

“无碰撞”开关仅在飞行期间生效，可在飞行中切换，选择会自动保存。开启时通过载具 Actor 的整体开关禁用碰撞，保持各组件原有碰撞模式，并使用无扫掠位移；关闭时恢复原有碰撞并启用位移碰撞扫描，飞行继续运行，遇到墙体或实体会受阻。飞行期间关闭车身重力并提高角阻尼。开启前保存原始状态，关闭飞行、下车、换车或切换场景时在游戏线程恢复；其他组件不逐帧扫描。游戏调整载具位置后，插件会从游戏确认的位置继续响应飞行操作。

0.1.26 只使用官方 Anomaly 公开插件接口，无需替换宿主或其他运行包文件。分享或安装时提供完整的 `VehicleFlight` 文件夹，保留 `plugin.dll`、`manifest.json`、`profile/` 和 `locales/`。

面板底部只显示操作说明。热载、停用或卸载插件前，必须先关闭载具飞行，并保持游戏运行，等待开关稳定保持关闭状态。物理状态在下一次游戏线程更新时恢复；恢复尚未完成时开关会继续显示为开启。飞行中直接停用或卸载不受支持；宿主可能隔离该插件，此时需要重启游戏，不能直接再次启用。

快捷键和速度会自动保存，进入游戏后需手动开启飞行。旧配置中的控制模式和穿墙偏好不再决定操作行为。

## 构建

```powershell
cmake --preset windows-vs2022
cmake --build --preset windows-relwithdebinfo --target anomaly_builtin_vehicle_flight
```

无碰撞模式下，如果组合位姿更新失败，会核对实际位置并尝试单独更新位置，避免误判受阻。有碰撞模式根据经过反射校验的命中法线尝试沿墙面滑动，目标位置以实际扫掠结果为准，可后退和侧移脱离实体。

物理控制优先使用 Actor 的物理根组件；非物理根组件的载具只查找骨骼车身，不再把任意轮胎或装饰组件当作车身处理。

# Changelog

## 0.4.0-alpha.3 - 2026-11-05

### 修复与改进

- 签名、GObjects/反射/DataTable 布局与虚表槽位迁移到
  `profile/compatibility.profile.json`，由宿主 `anomaly.profile` 校验后加载；
  代码只保留指令解码与语义校验，缺项或失配时相关功能确定性停用。
- 补齐设置页与开发者页缺失的中文文案（锁定/折叠/置顶/离战隐藏、Overlay 开关、
  导出结果等），窗口标题、开发者页签和 Overlay `DPS` 表头改走本地化目录。
- UID 探测与角色属性的离线夹具改为由随包 Profile 派生布局，不再复制代码中的兼容数值。

## 0.4.0-alpha.1 - 2026-08-30

首个公开 Alpha 版本。

### 功能

- 提供实时输出与承伤统计、遭遇 DPS、10 秒 DPS、伤害来源下钻和历史战斗浏览。
- 提供纯 Win32 透明置顶 Overlay，并与游戏内插件菜单共享显示设置。
- 将宿主可见的完整伤害事件写入可重放的 JSON Lines 报告。
- 使用包内资源补充角色、敌人、技能和伤害来源的中文名称。

### 修复与改进

- 按角色属性提供稳定配色，并统一实时与历史视图的颜色解析。
- 修复伤害来源 ID 被 Runtime 复用时可能产生的错误归因。
- 收紧 Overlay 汇总布局、历史元数据和配置同步行为。

### 已知限制

- 仅支持 Windows x64、NTE 和提供 Plugin API 1 的 Anomaly 1.7.x Runtime。
- 数据来自客户端伤害广播，不是服务端权威战斗日志，也不包含治疗、Buff 或施法事件。
- NTE 或 Anomaly 更新可能使采集服务暂时不可用；第三方原生插件还存在崩溃与账号风险。

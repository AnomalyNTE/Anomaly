# AutoClaw（自动抓娃娃）0.1.6

独立的 Anomaly 娃娃机插件，插件 ID：`b1ank.autoclaw`。

## 新增与调整

- 选择当前机器内的目标娃娃，手动投币获确认后自动提交一次抓取。
- 显示游戏确认的抓取结果和物品。
- 兼容配置接入框架 Profile 和签名更新服务，完善中文本地化。

## 修复

- 机器识别改为批量读取当前场景的 Actor，并复用本轮类型判断，加快列表出现速度。
- 物品名称改为按字段名及类型读取，适配新版本数据布局。
- 界面查询和抓取改用框架公开调用接口，完善参数和对象校验。
- 保持启动默认关闭识别，场景或玩家变化后自动停止。

## 使用

1. 将完整 `AutoClaw` 文件夹放入 `Anomaly/plugins/`，启用“自动抓娃娃”。
2. 进入游戏后，在插件窗口勾选“启用娃娃机识别”。
3. 打开娃娃机，等待列表出现，先选择目标，再在游戏里手动投币。
4. 游戏确认投币后自动抓取，本轮无需再次点击或手动下爪。

每轮只提交一次，结果和奖励以游戏结算为准。插件不会自动投币。投币后改选只影响下一轮；切换机器或重载后需重新选择。
